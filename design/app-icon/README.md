# 앱 아이콘 시안

Pullshot 앱 아이콘 시안 다섯 개와 앱에 붙인 아이콘 세 가지입니다. 앱 아이콘은 `make app`이 `make-icns.sh`로 `.icns`를 만들어 앱에 넣습니다.

## 파일

- `concept-<번호>-<이름>.svg`: 시안 원본입니다.
- `concept-<번호>-<이름>.png`: 원본을 1024x1024로 그린 것입니다.
- `concepts-light.png`, `concepts-dark.png`: 밝은 배경과 어두운 배경에서 시안마다 256, 128, 64, 32, 16 크기를 나란히 둔 비교 이미지입니다.
- `make-icns.sh`: 1024 PNG로 `.icns`를 만드는 스크립트입니다. 작은 크기용 PNG를 함께 주면 16, 32 크기 칸은 그 그림으로 만듭니다.

## 공통 규격

- 1024x1024 캔버스 가운데에 824x824 둥근 사각형을 두고, 아래쪽에 은은한 그림자를 깔았습니다. 모서리는 macOS 아이콘처럼 곡률이 이어지는 모양이며 반지름 185.4에 해당합니다.
- 색은 앱 강조색 보라 `#7A69FF` 계열과 새 항목 표시 주황 `#FF9F2E`을 씁니다.
- 카드 속 장면은 하늘, 언덕, 해로 만든 가상 장면입니다. Nintendo 상표와 로고, 컨트롤러 모양, 실제 게임 캐릭터와 화면은 쓰지 않았습니다.

## 시안

1. 격자와 당김(`concept-1-grid-pull`): 앨범 격자 세 칸과 아래 화살표가 든 주황 원으로, 캡처 앨범에서 Mac으로 당겨 오는 일을 나타냅니다. 32에서도 보라 바탕의 세 칸과 주황 원이 남고, 16에서는 주황 원이 새 항목 표시처럼 보입니다.
2. 겹친 캡처(`concept-2-stacked-cards`): 16:9 캡처 카드 세 장이 부채꼴로 겹치고 맨 앞 카드가 아래로 빠져나온 모양으로, 게임별로 쌓인 캡처를 나타냅니다. 흰 테두리 덕분에 32에서도 카드 모양이 남지만, 이름의 Pull은 다른 시안보다 약하게 드러납니다.
3. 셔터 프레임(`concept-3-shutter-frame`): 16:9 화면 모서리 표시 안에 보라 조리개를 둔 모양으로, 게임 화면을 찍는 일을 나타냅니다. 32에서는 모서리 표시가 가늘어지고 16에서는 보라 점만 또렷하며, 바탕이 밝아 밝은 Dock에서는 테두리가 옅게 보입니다.
   - 3b 셔터와 게임패드(`concept-3b-shutter-gamepad`): 3번의 조리개 자리에 어느 회사 제품도 본뜨지 않은 일반 게임패드를 넣은 변형으로, 게임 화면을 찍는 앱이라는 점이 더 바로 드러납니다. 32에서도 손잡이 모양과 흰 십자 방향키가 남고 16에서는 아래가 파인 보라 덩어리가 되며, 3번과 견준 크기별 비교는 `concept-3b-compare.png`에 있습니다.
   - 3c 빨강 바탕(`concept-3c-red-gamepad`): 3b와 모양은 같고 바탕을 빨강 `#E60012`로, 괄호와 게임패드를 흰색으로, 오른쪽 위 점을 노랑 `#FFD23F`로 바꾼 색 변형입니다. 32에서도 흰 괄호와 손잡이 모양이 남고 16에서는 빨강 위 흰 틀이 되며, 3b와 견준 크기별 비교는 `concept-3c-compare.png`에 있습니다.
   - 3d 가는 선(`concept-3d-red-line`): 3c의 괄호와 게임패드를 1024 기준 38 굵기의 끝이 둥근 흰 선으로만 다시 그리고, 괄호를 게임패드 가까이 모으고 오른쪽 위 점을 뺀 변형으로, 3c 계열에서 고른 시안입니다. 32에서는 선이 흐려지고 16에서는 거의 사라져서 십자키와 단추를 뺀 56 굵기의 32, 16 크기용 판 `concept-3d-red-line-small`을 같은 배치로 따로 두었으며, 고치기 전과 견준 비교는 `concept-3d-final-compare.png`에, 고치기 전 배치에서 26 굵기 판 `concept-3d-red-line-thin`과 견준 비교는 `concept-3d-compare.png`에 있습니다.
4. 케이블과 사진(`concept-4-cable-photo`): 위에서 내려온 USB-C 단자와 그 아래 캡처 한 장으로, 케이블을 꽂아 캡처를 가져오는 쓰임새를 그대로 보여 줍니다. 64까지는 단자가 또렷하지만 32 아래에서는 단자가 보라 덩어리로 줄어들어, 다섯 시안 가운데 작은 크기에서 가장 약합니다.
5. P 모노그램(`concept-5-monogram-p`): 기둥 끝이 아래 화살표인 P이고, 고리 안에 하늘과 언덕 장면을 넣어 Pull과 shot을 한 글자에 담았습니다. 굵고 단순한 형태라 16에서도 P와 화살표를 알아볼 수 있습니다.

## 앱 아이콘 세 가지

설정에서 고르는 앱 아이콘 세 가지이며, 기본은 빨강입니다. 셋 모두 고친 3d와 같은 외곽과 괄호 배치에 38 굵기의 끝이 둥근 흰 선을 쓰고, 바탕은 렌더러가 색을 틀지 않도록 단색 위에 위아래 명암을 덧칠했습니다.

- 빨강(`icon-red-gamepad`): 고친 3d를 이름만 바꿔 옮긴 기본 아이콘으로, 바탕은 빨강 `#E60012`입니다.
- 보라(`icon-purple-gamepad`): 같은 그림에 바탕만 앱 강조색 보라 `#7A69FF`로 바꾸고, 흰 선이 잘 보이도록 위는 조금 밝게, 아래는 조금 짙게 했습니다.
- 셔터 프레임(`icon-shutter`): 같은 괄호 안에 게임패드 대신 원 하나와 조리개 날 여섯 개를 선으로 그린 조리개를 두었고, 바탕은 짙은 흑연색 `#2B2838`입니다.

아이콘마다 32, 16 크기에 쓸 56 굵기 판(`-small`)이 따로 있습니다. 게임패드 판은 십자키와 단추를 뺐고, 셔터 프레임 판은 조리개 날을 빼고 원과 가운데 육각형만 남겼습니다. 크기별 비교는 `icon-set-compare.png`에, 512 크기로 나란히 둔 그림은 `icon-set-preview.png`에 있습니다. `make app`은 이 판을 `make-icns.sh`에 함께 넘겨 16, 16@2x, 32 칸을 이 판으로 만듭니다.

## .icns 만들기

1024 PNG와 출력 경로를 넘기고, 작은 크기용 판이 있으면 셋째 인자로 넘깁니다. `sips`로 16, 32, 128, 256, 512 크기의 1x와 2x 그림을 만들고 `iconutil`로 묶으며, 작은 크기용 판을 주면 16, 16@2x, 32 칸은 그 판에서 만듭니다.

```bash
cd design/app-icon
./make-icns.sh icon-red-gamepad.png "$TMPDIR/icon-red-gamepad.icns" icon-red-gamepad-small.png
```

`make app`은 앱 아이콘 세 가지의 `.icns`를 `.build/app-icons/`에 만들어 번들의 `Contents/Resources/`에 넣은 뒤 서명합니다. `.icns`는 리포에 넣지 않습니다. `App/Info.plist`의 `CFBundleIconFile`이 빨강(`icon-red-gamepad`)이라 Finder, Launchpad, DMG에는 빨강이 보이고, 설정에서 고른 아이콘은 앱이 열려 있는 동안 Dock과 앱 전환기에만 보입니다.

SVG를 고쳤으면 PNG를 다시 그린 뒤 `.icns`를 만듭니다. 이번 PNG는 macOS AppKit의 `NSImage`로 SVG를 읽어 1024 크기로 그렸습니다.

```bash
cd design/app-icon
swiftc render.swift -o "$TMPDIR/render-icon"
"$TMPDIR/render-icon" concept-5-monogram-p.svg concept-5-monogram-p.png
```
